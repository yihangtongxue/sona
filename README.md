# Sona

把声音整理成文字，让内容更易读。

Sona 是一款桌面音频转录工具：在本机将音频转成文字，再按需使用你配置的 AI 模型整理成易读的文稿。

[版本发布页](https://github.com/yihangtongxue/sona/releases) · [问题反馈](https://github.com/yihangtongxue/sona/issues) · [作者主页](https://maxcosmos.top)

## 功能

- **本地转录**：选择或拖入音频，自动排队处理，支持查看和复制结果。
- **播客导入**：在「导入音频」选择小宇宙或 Apple Podcasts 卡片，粘贴公开单集链接并点击「获取并转录」，在「我的音频」查看获取进度及转录结果。
- **长录音分段**：每段最多 30 分钟，自动依次处理并合并为一份完整结果，不设录音总时长上限。
- **AI 整理**：优化标点、分段和明显识别错误，尽量保留原意，自动生成标题。
- **长文整理**：按模型预算自动切块，逐段整理后合并为一份文稿。
- **独立文稿**：整理结果单独保存，不需要对照原稿操作。
- **模型管理**：支持多个 AI 模型配置，测试通过后手动设置默认模型。
- **应用内更新**：检查新版本，确认后下载并重启更新。

当前不包含摘要、自动笔记、自定义整理提示词或 MCP。

## 安装

发布版本从 **1.0.0** 开始，安装包和后续更新统一通过 GitHub Releases 提供。

| 系统 | 安装包 | 要求 |
| --- | --- | --- |
| Windows | `Sona-版本-windows-x64-setup.exe` | Windows 10 1809+ / Windows 11，x64 |
| Mac | `Sona-版本-macos-arm64.dmg` | Apple 芯片，macOS 26+ |

**Windows**：运行安装程序，安装到当前用户目录。缺少 Microsoft WebView2 时，安装程序会联网安装微软运行时；不需要自行安装 Python 或 CUDA SDK。ZIP 用于应用内更新，首次安装请选择 setup.exe。

**Mac**：打开 DMG，将 **Sona** 拖到 **应用程序**，然后从应用程序中启动，不要一直从 DMG 中运行。

Mac 分发包未经过 Apple 公证，Windows 安装程序未配置 Authenticode 代码签名，首次安装可能出现系统安全提示。请确认下载来源可信，不要关闭系统安全保护。更新包使用独立的 Ed25519 签名验证来源和完整性。

如果之前使用过旧分发版本，需要手动覆盖安装此次 GitHub **1.0.0** 一次；原有文稿、模型及配置保留。此后在应用内接收递增版本的更新。

## 开始使用

1. 打开「设置」，准备一个音频转文字模型并设为默认。
2. 在「导入音频」的「本地文件」卡片选择或拖入文件，也可以选择播客平台卡片，粘贴单集链接并点击「获取并转录」，在「我的音频」等待转录完成。
3. 点击「查看结果」，阅读或复制文字。
4. 如需 AI 整理，先在「设置 → AI 模型」添加模型、测试连接并设为默认，再点击「优化转录」。
5. 整理完成后，在「文稿」中查看和复制结果。

仅做本地转录不需要 AI API Key。AI 配置支持 OpenAI、Claude、Google Gemini、智谱及 OpenAI 兼容接口；具体模型权限由接口提供方决定。普通供应商无需填写 API 地址。

## 数据与隐私

- **转录在本机完成**，不向远程语音识别服务上传音频；首次准备模型资源可能需要下载。
- **AI 整理会发送转录文字**到你配置的模型接口，可能产生费用。首次使用会请求确认，不会发送音频文件。
- AI API Key 使用 AES-256-GCM 加密保存在本机，数据库只保存引用。正常使用不访问钥匙串；旧 Key 首次迁移可能需要一次系统授权，成功后不再读取钥匙串。连接测试也会发起模型请求，可能产生费用。
- 加密凭据位于应用数据目录的 `credentials/`，解密密钥独立保存。macOS/Linux 限制为当前用户访问；Windows 额外使用当前账户 DPAPI 保护解密密钥。本地加密不能防止同一账户下的恶意程序；macOS/Linux 的完整凭据备份包含解密能力，应妥善保管。
- 转录成功后清理应用内的音频副本，保留文字和历史记录，**不会删除你选择的原始文件**。失败或取消的任务保留副本以便重试。
- 播客导入会联网获取公开页面及音频，转录仍在本机完成。首版支持单集 MP3/M4A 等音频文件（最多 2 GB），不支持节目主页批量导入、登录内容或 HLS 流。获取失败、取消或中断后可重新获取；转录失败则复用已下载音频。成功转录后保留来源和文字，清理下载的音频副本。
- 文稿和配置保存在本机。AI 处理内容的具体规则取决于你选择的服务；连接测试通过不代表套餐适用于文稿整理。
- 应用自动保存限量的本地诊断日志，不自动上传。导出日志仅含诊断元数据，不包含转录正文、API Key 或原始异常消息。

## 常见问题

**转录一直显示「等待模型」？**

到设置中准备音频转文字模型并设为默认，任务会自动继续。

**AI 整理失败？**

先查看失败原因，检查默认 AI 模型的连接、权限和额度，再点击重试。重试可能产生费用。

**在哪里更新？**

打开「设置 → 关于 → 检查更新」。有新版本时，按提示下载并重启；正在处理的任务需要先结束。

**遇到问题怎么反馈？**

在「设置 → 关于」点击「导出日志」，选择保存位置，然后附上操作步骤和截图提交问题。请勿发送密钥或含私人内容的截图。
