新增播客链接导入，粘贴小宇宙或 Apple Podcasts 的单集链接，即可获取音频并在本机转录。

- 「导入音频」改为本地文件、小宇宙和 Apple Podcasts 三张卡片，选择来源后按提示操作。
- 播客获取进度和转录结果统一显示在「我的音频」，支持取消、失败重试，并自动识别重复单集。
- 转录成功后保留来源、文字和历史记录，自动清理应用内音频副本；转录失败或取消时保留音频，方便重试。
- 完善 macOS 文件选择窗口、应用菜单及桌面对话框的中文显示。
- 默认 AI 模型支持查看详细配置；连接测试失败后取消默认状态，方便修改配置或删除，修复旧失败配置无法编辑的问题。

播客导入支持公开单集音频文件，单个文件最多 2 GB；暂不支持整个节目批量导入、需要登录的内容或 HLS 流。

现有 GitHub 版本可通过应用内检查更新升级，也可下载安装包覆盖安装，原有文稿、模型和配置保留。

Mac 要求 Apple 芯片、macOS 26 或更高版本。Windows 面向 x64。
Mac 应用尚未经过 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中点击「仍要打开」。
