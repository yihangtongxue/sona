Sona 1.5.0 新增本地 MCP 服务，可以让 Codex 等 AI 工具直接调用 Sona 转录。

- **AI 工具连接（MCP）**：Sona 内置本地 MCP 服务，仅监听本机并使用随机令牌校验。提供转录链接或本地文件、查询进度、获取全文（可带时间戳）、浏览历史和全文搜索五个工具；除转录外均为只读。
- **复制 Codex 配置**：在「设置 → AI 工具连接（MCP）」点击「复制 Codex 配置」，粘贴到 `~/.codex/config.toml` 即可在 Codex 桌面应用、CLI 和 IDE 插件中使用。配置不含令牌；Sona 未运行时会自动启动。
- **菜单栏常驻**：菜单栏图标显示 MCP 服务状态和进行中的任务，可快速打开 Sona 或复制 Codex 配置。
- **全文搜索**：在「我的音频」中搜索所有转录、字幕和文稿内容。
- **识别语言**：可在设置中手动指定 Whisper 识别语言，默认自动识别；通过 MCP 转录时也可单独指定。
- **更多导出格式**：转录可导出 SRT 字幕（使用原有分段时间戳）和 Markdown；文稿可导出 Markdown。

可通过应用内检查更新升级，也可下载 DMG 覆盖安装，原有文稿、模型和配置保留。首次打开时会为已有内容建立搜索索引。

Mac 要求 Apple 芯片、macOS 26 或更高版本。
