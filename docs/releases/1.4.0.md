Sona 1.4.0 起专注于 Apple 芯片 Mac。Windows 支持止于 1.3.1，此后仅支持 Apple 芯片 Mac。

- 移除 Windows 安装包、更新包及相关功能（系统托盘、NVIDIA 显卡加速组件等）；发布产物仅包含 Mac DMG 与应用内更新包。
- 转录引擎精简为 MLX Whisper 与 Apple Speech，移除不再使用的依赖，安装包与更新流程更简洁。
- 简化本地凭据、文件锁及后台下载进程管理，统一为 macOS 实现，行为保持不变。

Mac 用户可通过应用内检查更新升级，也可下载 DMG 覆盖安装，原有文稿、模型和配置保留。

已安装 Windows 1.3.1 的用户可继续使用现有版本，但不会再收到更新。

Mac 要求 Apple 芯片、macOS 26 或更高版本。
