新增 B站和 YouTube 视频导入。YouTube 优先获取已有字幕，没有可用字幕时再下载音轨并本地转录。

- 「导入音频」新增「哔哩哔哩」和「YouTube」卡片，获取进度与文字结果统一显示在「我的音频」。
- B站支持 BV/AV 视频链接、b23.tv 短链接及分享文案，默认获取第一P，也可通过链接指定分P；下载后在本地转换为 MP3 并转录。
- 修复 B站下载节点使用非标准端口时被拒绝的问题，优先使用标准 HTTPS 节点，并在下载失败时自动切换平台提供的备用节点。
- YouTube 支持公开单视频、短链接和 Shorts。默认获取原语言字幕，同语言下优先人工字幕，其次自动字幕；也可选择中、英、日、韩字幕，或始终使用本地转录。
- 字幕保留时间戳并标注来源与语言，可直接查看、复制和 AI 整理；有可用字幕时不下载音视频，也不需要安装语音模型。不使用平台自动翻译字幕。
- 无可用字幕或字幕获取失败时，自动下载原音轨并进入本地转录流程，显示回退原因；同一视频的不同链接自动定位已有记录。
- 完善获取任务的取消、重试、临时文件清理和错误记录，安装包包含 YouTube 所需的获取组件。

首版支持公开可访问的视频，暂不支持需要登录或付费的内容、直播及播放列表批量导入。平台验证、限流或网络限制可能影响获取；字幕上限为 8 MB，下载文件及转换后的音频分别最多 2 GB。

现有 GitHub 版本可通过应用内检查更新升级，也可下载安装包覆盖安装，原有文稿、模型和配置保留。数据库结构升级后，请继续使用新版应用打开数据。

Mac 要求 Apple 芯片、macOS 26 或更高版本；Windows 支持 x64、Windows 10 1809 或更高版本及 Windows 11。
