Mac 1.0.0 若无法检查更新，请从本页下载 DMG，退出 Sona 后覆盖安装到「应用程序」，原有文稿、模型和配置保留。安装后可点击「检查更新」确认是否正常。

Windows 1.0.0 可通过应用内检查更新升级，也可下载安装程序覆盖安装。

Mac 要求 Apple 芯片、macOS 26 或更高版本。Windows 面向 x64。
Mac 应用尚未经过 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中点击「仍要打开」。
