Sona GitHub 首发版本。

- 提供 Windows x64 安装程序和 Apple 芯片 Mac DMG。
- 应用内从 GitHub 检查、下载并安装后续更新，更新包经过 Ed25519 签名验证。
- 保留本地音频转录、AI 整理、文稿、模型管理和日志导出。

Mac 要求 Apple 芯片、macOS 26 或更高版本。Windows 面向 x64；缺少 WebView2 时安装程序会从微软下载运行时。

旧分发版本需手动安装本次 1.0.0 一次；原有文稿、模型和配置保留。此版本起使用 GitHub 更新源。

Mac 应用未经过 Apple 公证，Windows 安装程序未配置 Authenticode 代码签名，首次安装可能出现系统安全提示。
