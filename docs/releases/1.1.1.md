新增暗黑模式，统一 macOS 与 Windows 的主题配色，并优化列表、下拉框和 API Key 存储体验。

- 「设置 → 外观」支持浅色、深色和跟随系统，记住选择并在启动时恢复。
- macOS 原生标题栏随主题调整颜色，保留红黄绿按钮、拖动和双击缩放。
- Windows 使用自绘标题栏与按钮，统一顶部和菜单配色；通过系统窗口机制处理最小化、最大化、关闭、拖动、边缘缩放和贴靠，并适配多显示器缩放及任务栏边界。
- 优化「我的音频」和「文稿」表格的列宽、行高、长标题、状态展示和操作按钮，让列表更简洁紧凑。
- 主题模式和 AI 供应商下拉框改用统一的自定义样式，适配深浅主题，支持键盘选择、取消和菜单边界避让。
- API Key 改为本地加密存储，正常使用不再访问系统钥匙串；兼容旧凭据迁移，首次迁移可能需要一次系统授权。Windows 额外使用当前账户 DPAPI 保护解密密钥。

现有 GitHub 版本可通过应用内检查更新升级，也可下载安装包覆盖安装，原有文稿、模型和配置保留。

Mac 要求 Apple 芯片、macOS 26 或更高版本；Windows 支持 x64、Windows 10 1809 或更高版本及 Windows 11。
