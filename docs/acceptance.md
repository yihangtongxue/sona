# 修复验收

本轮仅修改代码并静态检查引用、状态分支及差异。未启动桌面应用、未运行测试、未调用原生工具、未下载真实模型，以下各项均待开发者执行。

## 自动回归测试

在项目根目录手动执行：

```sh
uv run python -m unittest discover -s tests -v
```

- `test_models.py`：环境隔离、v1 数据库实际升级、默认选择恢复、删除失败保留选择、删除记录与选择事务回滚、只读查询、注入模型定义、进度写库节流、暂停信号传递。
- `test_whisper.py`：本地小文件下载、HTTP 206 续传、错误 Range 响应、忽略 Range 的服务端、截断响应保留 partial、HTTP 416、哈希错误、校验阶段暂停、关闭取消、残留清理、删除权限错误、旧锁文件、活跃锁互斥、子进程强制退出后锁释放。

锁测试需要分别在 Windows 和 macOS/Linux 执行，单一平台通过不能替代另一平台的文件锁验证。强制退出用例只结束测试创建的子进程。

## GUI 与前后端交互

1. 首次启动停留在“选择音频”，确认不触发系统资源检测。转写、资料库和 AI 模型配置应明确标注尚未开放，新增 AI 模型按钮不可操作。
2. 仅使用 Tab、Enter、空格选择文件。点击选择与拖放都应显示同一个当前文件及大小；取消选择后清空显示。关闭文件对话框应保留之前的选择。
3. 拖入非音频、空文件、多个文件，应得到明确提示，并保留之前合法选择；再次选择同名文件仍应生效。拖到上传区外不能让页面导航到文件。
4. 从设置或资料库点击品牌，应返回选择音频页；导航的当前项应同步更新。
5. 首次进入模型设置进行查询；查询结束后切页返回复用状态。固定模型介绍不应被进度、错误信息替换。
6. 将桥接响应人为延迟，在轮询未完成时点击另一模型的操作。请求应串行，操作完成后不能被较旧列表覆盖，不应出现多条持续轮询链。
7. 下载 Whisper：开始接收响应后应显示真实已下载/总大小；未知总大小时不显示虚构百分比。下载时可切页，返回后继续显示进度。
8. 在下载、校验阶段分别暂停，应最终显示“已暂停”，partial 保留；继续下载应成功。若暂停时已进入最终安装提交，允许任务正常完成为“已安装”。
9. 中断网络或关闭应用，再次打开后应发现未完成下载。可继续，也可通过“清理文件”移除，不必先完整下载。
10. 同一环境同时启动两个实例管理同一模型，应只有一个实例执行下载/删除；另一个显示“其他实例处理中”。强制关闭持锁实例后，重新操作不应永久锁死。保留的 `.lock` 文件不用删除。
11. 对测试目录模拟文件占用/权限不足，删除应显示失败，默认选择保留；解除占用后重试成功，文件与默认选择应同步清理。
12. 设置默认模型并重启。首次确认资源可用后显示“默认模型”；查询未知或不支持时不应显示已可用。
13. 模型任务活跃时断开桥接，界面应提供重新连接；重新连接或重新进入设置后应恢复查询。确认没有默默发起新下载。
14. 在 720×480、960×640、大窗口以及放大文字的情况下检查导航、模型操作按钮、长文件名、长错误详情和滚动；按钮应可见、可聚焦，说明文字应可读。

## Apple 与环境隔离

1. 在支持的 macOS 上检查已安装、未安装、系统下载中、工具缺失及系统不支持的状态。只有明确点击下载才申请资源。
2. Apple 下载完成、失败或等待系统后进度条应收起。Apple 没有应用内暂停、删除入口，已提交的系统任务可能继续。
3. 分别使用 `SONA_ENV=development`、`test` 验证默认选择、Whisper 文件和数据库隔离；Apple 系统资源仍跨环境共享。

## 未覆盖的产品能力

本轮没有接入音频解码、实际转写、资料库持久化、AI 推理或正式安装包。文件选择校验只验证声明的 MIME/扩展名与非零大小，不能证明内容可被音频解码器读取。模型初始下载大小在获取下载源响应前保持未知。
