# 双平台发行验收清单

由开发者在真实安装版中验收。未勾选表示尚未确认，不代表功能失败；代码检查、模拟测试和真实使用不能互相替代。

## 安装与启动

- [ ] macOS 开发模式和安装版分别完整退出后重开，文件选择窗口的「打开 / 取消」、侧栏和应用菜单显示中文；系统及其他应用的语言保持不变。

- [ ] 在受支持的 Apple 芯片 Mac 上从 DMG 安装到应用程序，首次启动正常；同时检查从互联网下载的安装包带来的系统提示。
- [ ] 在没有 Python、uv、开发工具的受支持设备上完成转录和 AI 请求，确认原生辅助程序、依赖和钥匙串不依赖开发环境。
- [ ] 重启后保留数据；开发数据和安装版数据相互隔离；重复打开安装版不产生重复任务。
- [ ] 最小窗口、全屏、放大字体和键盘操作下，列表、弹窗、复制、正文单列及标题居中正常。

## 音频与转录

- [ ] 没有默认模型时导入显示等待；准备并选择模型后自动继续，多条音频依次排队。
- [ ] Apple Speech 和 Whisper 分别处理短/长中文音频以及 MP3、WAV、M4A 等支持格式；检查首尾文字、时间戳、复制和静音结果。
- [ ] 分别验证不足 30 分钟、恰好 30 分钟、30 分钟加短尾段、2 小时及超过 2 小时的录音：每段最多 30 分钟，最终只有一条完整结果，跨段时间戳连续且静音不压缩时间。
- [ ] 检查 30/60/90 分钟交界处的连续说话、末尾短语及跨语言内容；确认没有因分段遗漏音频，识别质量可接受。比较 2 小时及更长录音的内存峰值，区分音频/推理工作内存与累计文字结果。
- [ ] 在后续分段制造失败、取消、退出及 Windows GPU 故障：不把前面各段误报成完整结果，不提前删除音频副本，Apple 临时 WAV 能被清理；重试从开头开始。
- [ ] 打开较长转录时能先看到首批段落并继续操作；渲染过程中复制得到完整正文，切换页面或打开其他结果不会插入旧段落。
- [ ] 切换页面不中断任务；取消、损坏文件、资源不可用、识别进程异常和正常关闭后都能得到正确状态并重试，不保存半成品为完成。
- [ ] 成功保存且识别进程退出后仅清理应用内副本；失败、取消仍保留副本，用户原文件不变；清理失败不影响已完成文字。
- [ ] 模型下载可暂停/继续并校验；断网、损坏资源可重试；默认或使用中的模型不能误删。

## 播客与 B站链接导入

以下项目由开发者手动验收，本轮不启动应用、不运行测试、不打包。

- [ ] 「导入音频」以本地文件、小宇宙、Apple Podcasts、哔哩哔哩四张卡片展示；不同窗口宽度下卡片自动换行，本地卡片支持选择、拖放文件，导入进度和取消保持可用。检查 B站图标和弹窗在浅色、深色主题下均清晰可读。
- [ ] 点击播客卡片打开对应平台的链接弹窗，输入框自动获得焦点；关闭按钮、取消和 Escape 可关闭，返回卡片后焦点正确，各平台分别保留未提交链接。提交期间防止重复提交，失败后可修改链接重试。
- [ ] 在最小窗口中链接弹窗、按钮和错误提示可见且可通过键盘操作；粘贴其他平台链接时提示选择对应来源。本地文件导入完成导致页面切换时，已打开的链接弹窗自动关闭。
- [ ] 小宇宙、Apple Podcasts 各准备公开 MP3/M4A 单集，验证「获取并转录」立即进入「我的音频」，解析、下载、入库、转录始终是同一条记录；标题、播客名称、平台正确。
- [ ] Apple 链接分别覆盖国家路径、带中文标题、分享参数和页面/API 回退；失败应保留可重试记录，不下载其他单集。网页结构变化时需更新固定的 yt-dlp 版本并重新验收。
- [ ] 下载有 Content-Length 时展示百分比，无总长度时展示已下载大小；HTML 错误页面、空文件、传输中断或已知长度不符、超过 2 GB 的音频不进入转录队列。
- [ ] 没有默认模型或模型未准备好时，下载成功后显示「等待模型」，准备模型后自动转录；完成后可查看、复制、优化转录，音频副本按既有策略清理。
- [ ] 同一单集不同分享参数、Apple 国家路径、连续点击或多窗口同时提交，只有一条记录，并定位已有记录；已完成但音频副本已清理时仍定位已有结果。
- [ ] 获取排队、解析、下载及等待入库时可取消，后台进程退出后清理临时文件；取消过程中不能删除或重试，迟到进度不能恢复任务。
- [ ] 下载失败或获取取消后重新获取使用新解析的地址；转录失败或取消后重试使用已下载音频。整条记录删除后允许再次导入，文稿仍沿用独立保存规则。
- [ ] 正常退出和强制终止分别覆盖解析、下载、下载完成未入库及重命名未提交数据库；重启后中断下载需手动重试，已完成入库衔接自动恢复且不重复入库或转录。
- [ ] 本地导入占用音频库时，播客下载完成等待入库；本地导入结束后继续。获取期间安装更新被阻止，退出后无遗留下载进程。
- [ ] 错误域名、仿冒域名、节目主页、无单集 ID、内网地址及跳转至内网被拒绝；HLS 提示格式暂不支持，不把所有 HLS 一律声称为 DRM。
- [ ] 验证直连与系统代理；日志不包含单集标题、页面内容、临时音频 URL 或 Apple 请求凭据。
- [ ] macOS 和 Windows 打包后不依赖系统安装的 yt-dlp 或 FFmpeg；现有本地文件转录和历史记录可正常使用。

相关模拟用例位于 `tests/test_podcasts.py`，同样由开发者手动运行。

### B站新增验收

- [ ] BV、AV、b23.tv、移动端视频链接、带分享参数的链接和包含一个链接的分享文案均能导入；重复的 `p`、空值、零、负数、多个链接和仿冒域名被拒绝。
- [ ] 多P视频不带 `p` 时只转录第一P；`p=2` 只转录第二P；不存在的分P失败，不下载第一P作为回退。标题包含对应分P信息，来源显示作者和哔哩哔哩。
- [ ] 带声音的完整视频优先下载；仅有音画分离流时下载独立音轨。两条路径均转换成真正的 MP3，再交给 Apple Speech / Whisper 转录；音频首尾完整、时长正确，不依赖外部 FFmpeg。缺少 MP3 编码器时给出明确提示。
- [ ] 同一内容的 BV、AV、不同短链接在解析后合并为一条记录且只下载一次；不同分P保留不同记录。重启后分享链接仍定位已有记录，删除后允许重新导入。重复任务合并后列表保留原任务。
- [ ] 解析后等待下载授权、下载中、转 MP3 时取消或退出，子进程停止，临时视频和音频均被清理；转录失败后重试复用已有 MP3。
- [ ] 充电试看不会以完整视频导入；登录内容、番剧、互动视频、直播、合集、仅提供 HLS 或旧式分段文件时明确失败。风控、下架、网络错误均显示可理解的提示，不暴露签名 URL。
- [ ] 下载文件或转换音频超过 2 GB、磁盘不足、损坏文件时不入库；转换阶段显示「正在转换为 MP3」，完成后正常转录并按既有规则清理副本。
- [ ] 使用含小宇宙/Apple 记录、转录结果和文稿的 v7 数据库升级到当前 v9，历史数据保留，B站可入库，再次启动不重复迁移；旧程序拒绝打开 v9 数据库。
- [ ] macOS / Windows 安装版分别验证系统代理、完整下载及 PyAV 提取能力；小宇宙、Apple Podcasts、本地文件导入无回归。
- [ ] B站下载节点使用非默认端口时不再被固定端口列表拒绝；仍拒绝无效端口、内网、本机和非 HTTP(S) 地址，重定向后重新检查。用户输入的视频页面链接仍只接受标准端口。失败时控制台包含任务 ID、阶段、异常类型、错误码、HTTP 状态及代码位置，不包含签名 URL、标题、Cookie 或原始异常消息。

- [ ] 主节点连接失败、返回空内容或长度不足时切换到平台提供的同一媒体流备用节点；优先使用标准 HTTPS 地址，切换后清理旧的部分下载文件并重置进度。所有节点失败时保留底层错误类型和 HTTP 状态；磁盘写入错误、大小超限不轮询备用节点。

新增离线回归用例位于 `tests/test_bilibili.py` 和 `tests/test_media_transfer.py`，仅供开发者手动运行，本轮未执行测试套件。

### YouTube 新增验收

- [ ] 同步依赖后，公开视频普通链接、youtu.be、移动端、Shorts、单链接分享文案可导入；同一视频定位已有记录，频道和纯播放列表被拒绝。单视频带列表或时间参数时只获取该视频完整内容。
- [ ] 未安装语音模型时，原语言人工字幕可直接完成；没有人工字幕时使用原语言自动字幕。全程不下载音视频、不进入模型队列，来源和语言正确。
- [ ] 原语言英文视频带人工中文字幕时，默认保留英文，指定中文时取人工中文字幕；自动翻译轨道和 live_chat 不作为字幕。无法确定原语言且有多种字幕时不随机选择，转录原音轨。
- [ ] 无字幕、字幕为空或格式损坏时进入音轨下载和本地转录；字幕网络错误显示获取失败后回退，元数据获取失败直接报错，不误认为没有字幕。仅有字幕而没有可下载音轨时仍能完成字幕导入。
- [ ] 选择「始终本地转录」后不请求字幕；断网重试和重启后保留策略、语言。英文等非中文音轨使用支持对应语言的语音模型。
- [ ] JSON3/VTT 时间戳可查看；自动字幕滚动显示不重复整句，后续真实重复语句保留；长字幕结果分批渲染，复制正文和 AI 整理正常。
- [ ] 字幕结果显示「人工字幕」或「自动字幕」，大小栏显示「字幕」，不显示文件丢失；删除会清理来源与字幕，已创建文稿保留，删除后可重新导入。
- [ ] 字幕获取时、字幕已落盘待入库时、下载或转 MP3 时取消/退出，不出现晚到结果覆盖取消；已完成结果重启后仍可查看。macOS/Windows 退出或强制停止获取时不遗留 Deno 进程。
- [ ] v8 数据库升级到 v9，B站短链接别名、历史音频、转录和文稿保留；重复启动不重复迁移，旧应用拒绝打开新版数据库。
- [ ] 安装版在没有系统 Deno/Node/FFmpeg 的 macOS/Windows 上完成字幕和音轨路径；原有播客/B站导入正常。JavaScript 组件缺失时提示同步依赖或重新安装，不静默失败。
- [ ] 音轨分片缺失时任务失败，不跳过缺失片段生成不完整文字；网页/字幕超限、音轨超限、磁盘失败给出错误，日志不包含字幕正文、签名 URL 或 Cookie。

新增离线回归用例位于 `tests/test_youtube.py` 和 `tests/test_youtube_network.py`，供开发者同步依赖后手动执行。本轮仅更新代码、依赖锁文件及静态差异检查，未启动应用、运行测试或打包。

## AI 模型与文稿

- [ ] 新增 Key 后重启应用、反复测试连接、打开模型详情和生成文稿，不出现钥匙串授权。磁盘凭据不包含明文 Key，macOS 凭据目录权限为 700、文件为 600；Windows 主密钥无法由其他账户解密。
- [ ] 旧 Key 首次使用允许授权后完成迁移，重启不再授权；拒绝迁移不丢原配置，同一服务实例不反复弹窗，填写新 Key 可直接保存到本地。迁移保留测试状态和排队任务引用；清理凭据不访问钥匙串。
- [ ] 修改密文、将两条密文互换、删除或损坏主密钥均明确报错，不静默重建主密钥或回退钥匙串；不可写目录、保存中断不覆盖原配置，导出日志不包含凭据目录。
- [ ] 普通供应商隐藏默认地址，自定义接口必须填地址；密钥必填、默认隐藏，编辑回显与眼睛按钮正常。
- [ ] 首个模型只保存；测试成功后才能手动设为默认，默认模型不可编辑/删除。改名不重置验证，连接变化重置验证，切换供应商不沿用旧密钥。
- [ ] 测试错误密钥、无权限、无效模型、额度不足、断网、空回复和输出截断，提示可理解；保存失败不损坏原配置。
- [ ] 首次优化显示文字发送与费用提示；取消不创建任务。确认后再次优化、重启后优化不重复弹窗。旧版本留下的失败文稿首次重试也要确认。
- [ ] 提示期间切换页面或关闭，不处理错误的记录；快速重复点击不创建重复任务。直接桥接调用也不能绕过首次确认。
- [ ] 优化立即进入文稿列表并显示真实状态；完成后只有 AI 标题和正文，无原稿对照。长文检查内容完整、顺序、否定和数字，不能将截断正文标为完成。
- [ ] 优化失败可重试；仅标题失败时不重复整理正文。中途退出后显示中断，不自动重发已开始的请求。
- [ ] 删除原转录不影响文稿；处理中不可删除文稿；队列绑定原配置，不因为切换默认而静默改用别的端点。

## Windows 安装与更新

- [ ] 在未安装 Python、uv、CUDA SDK 的 Windows x64 设备上运行 setup.exe，安装到当前用户目录，快捷方式和首次启动正常。
- [ ] 缺少 WebView2 时可以联网安装；断网时安装程序明确提示，安装运行时后可重试。
- [ ] 安装版完成 CPU 转录、AI 请求、凭据保存和日志导出；应用关闭后没有阻止更新的残留子进程。
- [ ] 实际从 GitHub 1.0.0 更新至 1.0.1；退出主程序后替换成功，重启版本正确、原数据保留。
- [ ] Windows ZIP 路径穿越、ADS、设备名、大小写重复路径、符号链接及错误平台包均被拒绝。
- [ ] 独立更新程序重新验证原 ZIP；替换失败恢复原应用，文件占用、权限不足、磁盘不足不误报成功。
- [ ] 卸载删除应用程序和快捷方式，保留用户模型、文稿、数据库和系统凭据；重新安装后可继续使用。
