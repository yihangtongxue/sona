# 转录功能验收

以下由开发者执行。本次未启动应用、未运行测试、未下载真实模型或编译原生工具；Apple Speech 接入沿用现有 Python 依赖。

## 准备

在 Windows x64 与 Mac M5（原生 ARM64 Python）分别同步依赖并启动：

```sh
uv sync
uv run sona
```

Windows NVIDIA 路径需有兼容驱动；运行库由“模型设置 → 转录加速”按用户选择下载。应分别验收无 NVIDIA 显卡、有 NVIDIA 但未下载组件、组件已启用三种情况。MLX 仅需在 Mac 上安装，Windows 不应拉取 MLX / PyTorch 的 Mac 依赖链。

## 转录加速

1. 首次启动有 NVIDIA 的 Windows：设置页显示“下载并启用”和约 1.4 GiB 的下载大小；未点击时不请求 NVIDIA 下载地址，导入音频直接使用 CPU。
2. 无可用 NVIDIA 时显示“当前使用 CPU 转录”；驱动检测异常显示检查失败，不能误报“没有显卡”。Mac M5 显示 Apple 芯片加速，不出现 Windows 下载按钮。
3. 点击下载后核对进度、暂停和继续；断网显示失败并可重试，不能丢弃已经收到的有效部分。服务端忽略 Range 时应重新下载该文件，不能直接追加。
4. 下载中正常关闭或强制结束，再启动应停留在暂停状态；只有点击继续才联网。已下载未启用的组件重启后保持关闭。
5. 下载期间导入音频仍以 CPU 完成；组件检查通过之后开始的任务使用 NVIDIA GPU，正在执行的 CPU 任务不重启。
6. 控制台必须分别出现归档校验、cuBLAS 矩阵运算通过、cuDNN 卷积运算通过。只有这两项真实运算均通过才能显示已启用。
7. 在没有系统 CUDA SDK / PATH 配置的机器上验收；确认能够定位应用数据目录中的运行库，避免继续依赖手动安装的 DLL。
8. 关闭加速后文件仍保留、之后任务使用 CPU；再启用只做本地检查，不重复下载。当前 GPU 任务不中断。
9. 让显卡识别失败或显存不足：本条任务最多回退 CPU 一次，下一条直接 CPU；设置页显示暂不可用，可重新检查。旧任务的失败不能覆盖之后完成的新检查。
10. 损坏归档、损坏已安装文件、磁盘空间不足、杀毒软件阻止 DLL、过旧驱动分别核对错误状态和控制台原因；损坏文件不能显示已启用。
11. 同开两个窗口，下载操作不能并发；另一窗口暂停可以生效。强制结束操作所属窗口后，剩余窗口能恢复暂停状态，不自动续传。
12. 720×480、960×640、系统字体放大下检查新区域的换行、按钮边框、键盘焦点、进度显示；其他页面保持原有精简布局。

## 核心流程

1. 首次进入上传页只有上传区域。在没有默认模型时导入一段中文录音：自动进入“我的音频”，出现“等待模型”。
2. 在模型设置下载 Small 并设为默认，回到列表：原任务应自动转录，无需再次上传。
3. 完成后显示“已完成”和“查看结果”；核对文字、时间戳、全文复制，“打开音频”入口已移除。确认识别进程退出、结果入库后应用内副本自动删除，列表不误报“文件已丢失”；原始文件保持不变。
4. 第一条转录时继续导入第二条：第二条显示“排队中”，先后执行，不同时加载两个模型。
5. 转录过程中切换所有页面，任务不中断。后台阶段更新不抢焦点，展开的原因仍可阅读。
6. 取消排队任务不启动识别。取消进行中的任务应停止子进程，最终显示“已取消”；可以重试。
7. 损坏音频、伪装扩展名、无法解码音轨应显示“转录失败”和原因，保留文件；无语音的有效音频允许完成并显示“未识别到语音”。
8. 缺少识别 Python 包或运行库时，应说明失败原因。NVIDIA 初始化错误、显存不足或 GPU 进程异常时只回退 CPU 一次，不能无限重试。
9. Mac M5 实际确认使用 Apple GPU。Windows CPU 与 GPU 分别记录相同录音的耗时、内存 / 显存和结果差异；不要用一种设备的测试替代另一种。
10. 长录音、中文夹英文、静音较多、噪声和多人录音分别核对漏字、重复、幻觉及时间戳。当前不区分说话人。

## 持久化与竞争

1. 转录完成后重启，副本已清理但历史、文字、时间戳仍可查看和复制；原始文件不变。启动后历史已完成且有结果的副本也会清理，未完成 / 失败 / 取消的副本保留。
2. 转录中正常关闭应用，再次打开后重新排队并处理整条音频。
3. 强制结束应用后重新启动：任务不能永远停留在“转录中”；旧子进程应退出，模型锁最终释放。
4. 同一环境开启两个实例，只允许一个实例调度转录；在另一个窗口取消也应生效。
5. 接近转录完成时取消：只允许“已完成”或“已取消”之一，不出现已取消后又被迟到结果覆盖。
6. 转录中不能直接删除音频；取消结束后再删除，音频副本、任务与结果同时从列表消失，原文件保留。
7. 删除后立即刷新和重启，不应因迟到的进度 / 结果重新出现记录。
8. 导入后修改默认模型，已有模型绑定的任务仍使用原模型；失败 / 取消后重试使用新的默认选择。
9. 测试导入中取消、关闭、数据库提交失败：不得出现半个音频的转录任务。
10. 删除数据库事务失败应恢复文件；提交成功但待清理文件 unlink 失败，记录保持删除，下次启动清理残留。
11. 模拟转录结果事务失败、取消抢先提交、只有 completed 状态却没有结果：不得自动清理音频。静音正常完成且结果已保存时允许清理。模拟文件占用或无删除权限：结果仍然完成且可查看，后续空闲检查或重启后重试清理。
12. 导入占用音频目录锁时清理延后，不影响导入；两实例仅由持有转录调度锁的实例清理。副本清理后再次点击列表“删除”，仍能删除记录与文字结果；若想重新转录，需重新导入原文件。

## 模型资源与界面

1. 旧 `.pt` 存在时，不能直接显示新引擎“已安装”；下载新格式后旧文件仍存在。
2. Windows 模型目录含 CTranslate2 权重、配置、词表 / tokenizer；Mac 含 MLX 权重和配置，均有完整清单。
3. 下载进度依据清单总大小和实际接收字节；暂停、网络中断和重启后可以继续。校验失败不能进入已安装状态。
4. 缺少某个配置或权重文件时，重新进入设置应自动检查并要求重新下载。
5. 正在转录的模型不能被删除，界面说明占用；结束后重试可删除。
6. 默认模型不显示删除 / 清理按钮，直接调用删除接口也应被拒绝；切换其他默认模型后才允许删除原模型。删除同时清理旧格式及未完成下载，当前默认选择不受影响。另一个窗口切换默认与当前窗口删除操作不能产生竞争。
7. Apple Speech 查询 / 下载系统语言资源；资源可用后显示“设为默认”，选中后显示“默认模型”。不显示模型文件大小、暂停或删除按钮。
8. 720×480、960×640 和放大字体下核对表格滚动、长文件名、状态和按钮；列表页没有多余标题、说明或添加音频按钮。
9. 列表轮询和用户操作请求串行，不因为轮询吞掉点击；离开列表停止轮询，回到列表立即读取最新状态。
10. 音频记录 / 错误文本中的 HTML 字符只能作为文字显示。查看结果后快速切页，迟到响应不能切回结果页。
11. 正常模型不显示“刷新状态”按钮。当前模型只显示“默认模型”标记，其他已安装模型可“设为默认”；失败时显示明确的重试操作，系统下载等待结束或使用锁释放后自动更新。切走再回到设置会重新检查本机资源。

## AI 模型配置

1. 新增配置时依次选择 OpenAI、Claude、Gemini、智谱 GLM、智谱 Coding Plan：不显示 API 地址输入框；模型标识和密钥必填，模型名称留空时使用模型标识。只保存不产生模型请求。智谱 GLM 使用国内 `/api/paas/v4`，智谱 Coding Plan 使用国内 `/api/coding/paas/v4`；分别保存并重启后检查选项回显，切换两者不会沿用旧密钥或自定义地址。
2. 选择“自定义接口”后显示且要求填写 API 地址；所有供应商的 API Key 均必填，不显示“可选”。新增和编辑时，空值或纯空格密钥均不能保存，直接调用后端也应拒绝；已有配置和凭据不受失败保存影响。切换供应商清空旧的模型标识、地址及本次输入的密钥，避免填错供应商。
3. 保存第一个模型也不自动测试、不自动设为默认；未测试和测试失败时禁用“设为默认”，直接调用后端也应拒绝。测试通过后手动设为默认，多个配置中只能有一个默认。当前默认模型不可编辑、不可删除，前后端均校验；先将另一个测试通过的模型设为默认，旧默认才恢复编辑、删除权限。验证另一实例切换默认后，旧窗口保存被拒绝且不修改凭据。切页、重启后保留配置、测试状态和默认选择。
4. 编辑已有配置时从系统凭据存储回填 API Key，默认圆点隐藏；眼睛按钮可显示 / 隐藏，支持键盘操作，新增模型也可切换。列表接口不返回密钥。读取中禁止修改与保存，但允许取消；取消后快速打开其他模型，迟到结果不能回填到新弹窗。读取失败显示提示，需重新打开成功读取或填写新密钥后才能保存。切换供应商、恢复官方地址会清空密钥并恢复隐藏；修改地址清空自动回填的密钥，避免发往新接口。已有自定义地址不能被隐藏或静默替换。
5. 保存期间按钮禁用，不能重复提交或关闭弹窗。保存失败应在弹窗内说明原因并保留输入；成功或取消后清空密码输入框。仅改显示名称或直接保存，不重写未变化的密钥，保留测试状态、时间和错误；更改供应商、模型标识、实际地址、密钥或高级配置才重置为未测试，需重新测试后才能设为默认。
6. 主动点击“测试连接”会产生一条可能计费的简短请求。分别验收成功、错误密钥、无模型权限、无效模型、额度不足、断网：显示对应提示；无 choices、空正文、仅推理而无正文、内容被拦截时不能记为通过。测试结束后恢复按钮。上次失败原因可在编辑弹窗和列表的折叠“错误详情”查看，不依赖临时提示。默认模型可重新测试，失败时保留默认选择及编辑、删除保护，不自动切换其他模型。
7. 密钥保存使用系统凭据存储，SQLite 仅保存引用。模拟数据库写入失败后，新密钥应被清理；修改密钥时提交成功后再清理旧密钥；删除或中断后的清理失败会记录引用，下一次模型操作重试。检查错误消息及应用日志不包含真实密钥。
8. 在 720×480、960×640 和放大字体时检查弹窗滚动、底部保存按钮及键盘操作。确认音频转录模型和默认选择不受影响。
9. 智谱 GLM-5.3 / GLM-5.3-Flash 测试使用 4096 tokens、45 秒超时、启用思考且强度为 low；其他模型默认 1024 tokens、30 秒，不注入不受支持的智谱参数。每次点击只请求一次，不自动重试或更换端点。`length` 要提示单次输出截断而不是套餐耗尽；检查日志包含安全终止原因及字符数，不包含回复正文、思考原文或密钥。参数依据和套餐适用限制见 [AI 模型连接测试](ai-model-testing.md)。

以上为待执行的手动验收，未使用真实 API Key 调用供应商。

智谱 Coding Plan 地址依据[官方接入文档](https://docs.bigmodel.cn/cn/coding-plan/quick-start)。官方限定套餐用于支持的工具与产品环境；加入接口配置不代表 Sona 已获官方支持，也不保证请求抵扣套餐额度。

## 文稿整理

1. 尚未设置默认 AI 模型或默认模型测试失败时，点击“优化转录”应提示前往设置，不创建空任务；空转录不能优化。
2. 打开转录结果，点击“复制全文”旁的“优化转录”：立即创建一份文稿并进入“文稿”菜单；请求期间按钮禁用。列表显示“待整理文稿”和排队 / 正在优化状态，不使用音频名称作为标题。切换菜单或查看其他记录不影响后台处理，迟到响应不能强制跳转页面。
3. 成功后显示 AI 生成的简短标题，点击“查看”只有标题和正文，可复制全文、返回列表；不显示原稿、时间戳或关联音频入口。正文应遵守中文口语弱优化要求，不出现解释或新加的总结。
4. 长文本显示分段进度，所有输入按顺序处理。检查首尾内容、段落衔接和有意义的重复、否定、数字是否保留；模拟空回复、输出达到上限、内容拦截、工具调用或网络异常，不能把半成品标为完成。
5. 正文失败时显示原因及重试；仅标题失败时保留内部正文、重试不重复整理正文。重试使用当时的默认模型。已经完成或正在处理的文稿不能重试。
6. 在优化过程中删除原音频记录，任务仍可完成；删除完成文稿不影响原转录。处理中禁止删除文稿；失败、完成后可确认删除。新建表不含指向音频或模型配置的外键，完成后清空输入快照及内部模型引用。
7. 创建后切换默认模型，原任务不改用新供应商；排队期间原模型被编辑、删除或测试失败时应明确失败，不发送到替代地址。生成请求只使用绑定配置和内存密钥，错误与应用日志不包含正文、密钥或供应商原始异常。
8. 优化中关闭并重启，任务显示中断并允许手动重试，不自动重复已开始的请求；尚未开始的任务继续排队。同一数据目录打开两个实例，只允许一个文稿调度者执行，不重复扣费。
9. 720×480、960×640、全屏及放大字体下检查新增菜单、列表横向滚动和正文阅读，文稿正文始终单列。复制包含换行的中文及类似 HTML 的文本，确认以纯文本呈现，不执行其中的脚本。

文稿功能会向所配置的模型接口发送文本，正文分段和标题生成均可能计费。以上仅为待执行验收，不由开发助手发起真实模型请求。

## Apple Speech 完整流程

1. 在支持的 macOS 26+ 设备上使用最新版原生工具；已有资源时直接设为默认，未安装时点击下载、观察系统进度并确认安装。自动检查和开始转录不能触发隐式下载。
2. 没有默认模型时先导入音频，再选择 Apple Speech：等待任务自动开始；已有默认 Apple Speech 时导入音频应直接排队。
3. 分别转录中文 WAV、MP3、M4A，以及应用支持但 AVAudioFile 未必直接支持的格式（如 WebM / OGG）；确认完整文字、时间戳、复制和重启后的结果查看。长录音检查末尾内容完整且无重复片段。
4. 静音音频显示“未识别到语音”；损坏音频、系统资源不可用、工具异常退出或超时显示原因并保留音频，不能把部分结果标记为完成。
5. 分别在解码、原生识别和整理结果时取消，确认 Python 与原生工具都结束，临时音频清理，取消后的任务可重试。正常关闭后再次打开应重新处理整条音频。
6. Apple Speech 与 Whisper 之间切换默认模型：新导入和未绑定任务使用新选择，已经绑定的排队 / 进行中任务保持原选择，失败或取消后重试使用当前默认模型。
7. 使用当前表结构的数据库验收：新建数据库时直接初始化全部表和导入触发器，Apple Speech 可绑定新导入任务；重复启动保留当前数据库内的音频、结果及默认选择。不做旧版本数据库升级验收。
8. 不支持的系统、设备或语言应显示不可用；`SONA_SPEECH_HELPER` 指向旧版仅支持资源管理的工具时应提示更新，不能误报为可以转录。Apple 路径不应加载 MLX / faster-whisper 或执行 CUDA 回退。

## 控制台日志

1. 从终端启动后应立即输出平台、Python 版本、数据目录和识别引擎；每条日志包含时间、级别和 PID。
2. 导入并转录一段音频，用任务 ID 对照主进程与识别子进程日志，确认能看到解码、CUDA 设备数 / Apple GPU、模型加载、耗时及结果保存。
3. GPU 失败时应输出原始错误与回退原因；子进程异常退出时输出退出码。取消和正常关闭也应有结束日志。
4. 日志不包含音频数据或转录正文；轮询和成功的音频分块不刷屏。设置 `SONA_LOG_LEVEL=DEBUG` 后可查看更详细的进度事件。
