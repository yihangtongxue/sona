# 双平台发行验收清单

由开发者在真实安装版中验收。未勾选表示尚未确认，不代表功能失败；代码检查、模拟测试和真实使用不能互相替代。

## 安装与启动

- [ ] 在受支持的 Apple 芯片 Mac 上从 DMG 安装到应用程序，首次启动正常；同时检查从互联网下载的安装包带来的系统提示。
- [ ] 在没有 Python、uv、开发工具的受支持设备上完成转录和 AI 请求，确认原生辅助程序、依赖和钥匙串不依赖开发环境。
- [ ] 重启后保留数据；开发数据和安装版数据相互隔离；重复打开安装版不产生重复任务。
- [ ] 最小窗口、全屏、放大字体和键盘操作下，列表、弹窗、复制、正文单列及标题居中正常。

## 音频与转录

- [ ] 没有默认模型时导入显示等待；准备并选择模型后自动继续，多条音频依次排队。
- [ ] Apple Speech 和 Whisper 分别处理短/长中文音频以及 MP3、WAV、M4A 等支持格式；检查首尾文字、时间戳、复制和静音结果。
- [ ] 分别验证不足 30 分钟、恰好 30 分钟、30 分钟加短尾段、2 小时及超过 2 小时的录音：每段最多 30 分钟，最终只有一条完整结果，跨段时间戳连续且静音不压缩时间。
- [ ] 检查 30/60/90 分钟交界处的连续说话、末尾短语及跨语言内容；确认没有因分段遗漏音频，识别质量可接受。比较 2 小时及更长录音的内存峰值，区分音频/推理工作内存与累计文字结果。
- [ ] 在后续分段制造失败、取消、退出及 Windows GPU 故障：不把前面各段误报成完整结果，不提前删除音频副本，Apple 临时 WAV 能被清理；重试从开头开始。
- [ ] 打开较长转录时能先看到首批段落并继续操作；渲染过程中复制得到完整正文，切换页面或打开其他结果不会插入旧段落。
- [ ] 切换页面不中断任务；取消、损坏文件、资源不可用、识别进程异常和正常关闭后都能得到正确状态并重试，不保存半成品为完成。
- [ ] 成功保存且识别进程退出后仅清理应用内副本；失败、取消仍保留副本，用户原文件不变；清理失败不影响已完成文字。
- [ ] 模型下载可暂停/继续并校验；断网、损坏资源可重试；默认或使用中的模型不能误删。

## AI 模型与文稿

- [ ] 普通供应商隐藏默认地址，自定义接口必须填地址；密钥必填、默认隐藏，编辑回显与眼睛按钮正常。
- [ ] 首个模型只保存；测试成功后才能手动设为默认，默认模型不可编辑/删除。改名不重置验证，连接变化重置验证，切换供应商不沿用旧密钥。
- [ ] 测试错误密钥、无权限、无效模型、额度不足、断网、空回复和输出截断，提示可理解；保存失败不损坏原配置。
- [ ] 首次优化显示文字发送与费用提示；取消不创建任务。确认后再次优化、重启后优化不重复弹窗。旧版本留下的失败文稿首次重试也要确认。
- [ ] 提示期间切换页面或关闭，不处理错误的记录；快速重复点击不创建重复任务。直接桥接调用也不能绕过首次确认。
- [ ] 优化立即进入文稿列表并显示真实状态；完成后只有 AI 标题和正文，无原稿对照。长文检查内容完整、顺序、否定和数字，不能将截断正文标为完成。
- [ ] 优化失败可重试；仅标题失败时不重复整理正文。中途退出后显示中断，不自动重发已开始的请求。
- [ ] 删除原转录不影响文稿；处理中不可删除文稿；队列绑定原配置，不因为切换默认而静默改用别的端点。

## 日志与更新

- [ ] 从 Finder 启动后有本地诊断日志，转录子进程和错误也有对应代码位置；连续使用后文件数量和大小受限。
- [ ] 「关于 → 导出日志」可保存 ZIP；取消不导出；不可写位置、磁盘不足或日志忙时提示重试，不阻断其他功能。
- [ ] 用虚构敏感样本确认导出包没有正文、密钥、个人路径、原始异常、数据库或音频；日志不会自动上传。
- [ ] GitHub Release 同时包含双平台安装包、更新 ZIP、签名、SHA256SUMS.txt 和 stable.json；清单及附件可匿名下载，大小和哈希匹配。
- [ ] 任一平台构建失败时不发布；附件上传失败时保持草稿；重复发布相同版本、发布更低版本均被拒绝。
- [ ] 实际完成一次受控的 1.0.0 → 1.0.1 升级，启动新版后保留模型、钥匙串、转录和文稿；处理中不能重启更新。
- [ ] 断网、取消、错误签名、错误版本/架构、磁盘不足和替换失败不误报成功；按 [发布指南](github-releases.md) 确认旧应用及数据库恢复路径。

## 回归与范围

模拟测试由开发者手动执行：`uv run python -m unittest discover -s tests -v`。新增 `test_consent.py` 与 `test_diagnostics.py`，其余用例覆盖存储、队列、模型、文稿、原生协议、下载和更新。本轮未运行测试。

Windows 源码回归另检查 CPU/NVIDIA、驱动不可用、组件下载暂停/恢复、运行库损坏、真实运算门控及 GPU 失败后单次 CPU 回退。Windows 安装、更新和卸载也属于本次双平台发行验收范围。

## Windows 安装与更新

- [ ] 在未安装 Python、uv、CUDA SDK 的 Windows x64 设备上运行 setup.exe，安装到当前用户目录，快捷方式和首次启动正常。
- [ ] 缺少 WebView2 时可以联网安装；断网时安装程序明确提示，安装运行时后可重试。
- [ ] 安装版完成 CPU 转录、AI 请求、凭据保存和日志导出；应用关闭后没有阻止更新的残留子进程。
- [ ] 实际从 GitHub 1.0.0 更新至 1.0.1；退出主程序后替换成功，重启版本正确、原数据保留。
- [ ] Windows ZIP 路径穿越、ADS、设备名、大小写重复路径、符号链接及错误平台包均被拒绝。
- [ ] 独立更新程序重新验证原 ZIP；替换失败恢复原应用，文件占用、权限不足、磁盘不足不误报成功。
- [ ] 卸载删除应用程序和快捷方式，保留用户模型、文稿、数据库和系统凭据；重新安装后可继续使用。
